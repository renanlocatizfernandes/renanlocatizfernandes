## 🚀 Projeto Principal

### ⚽ [Futeba dos Parças](https://futebadosparcas.web.app)

[![Android CI](https://github.com/TechFernandesLTDA/futeba-dos-parcas/actions/workflows/android-ci.yml/badge.svg)](https://github.com/TechFernandesLTDA/futeba-dos-parcas/actions/workflows/android-ci.yml)
[![Version](https://img.shields.io/badge/version-1.21.3-green.svg)](https://github.com/TechFernandesLTDA/futeba-dos-parcas/releases)

App completo para organização de peladas com:
- 🏆 Sistema de XP, níveis e ligas ranqueadas
- 📊 Estatísticas, badges e conquistas
- 🗺️ Localização de quadras e arenas via Google Maps
- 💰 Caixinha do grupo e gestão financeira
- 🔔 Notificações push e Cloud Functions
- 📱 Android nativo + Web PWA + Cloud Functions

| Android | Web |
|---------|-----|
| Kotlin + Compose + KMP | React + MUI + Vite |
| Firebase Android SDK | Firebase Web SDK v10 |
| Koin DI + Coroutines | TanStack Query + Context |
